# PT-BR i18n + Language Selector Implementation Plan

## Overview

Introduzir uma camada fina de i18n (`t` / `tf`) com catálogo Python PT-BR, default `pt_BR` no fork, msgid = texto inglês (templates com `.format()`), fallback EN para sync com upstream. Cobrir copy do app, Data Dragon `pt_BR`, CHANGELOG, tips/LLM e DraftBoard no idioma do host. Seletor de idioma nas Settings na fase final. Voz TTS permanece EN; texto falado/escrito do tempo usa o catálogo.

## Current State Analysis

- Zero i18n hoje: literais EN espalhados em `core/`, `ui/`, AHK, `docs/draft/index.html`, `CHANGELOG.md`.
- Prefs em `core/smiteconfig.py` (`STRINGS` / `BOOLS` / `DEFAULTS`) → `~/.claude/smiteless_settings.json`; Settings em `ui/smitesettings.py` sem controle de idioma.
- Texto dinâmico nasce no Python (ex. `lolqueue`, `loltempo`, `loldead`, `lolload`) e a UI só exibe.
- Data Dragon fixo em `en_US` (`core/lolbuild.py:90`; DraftBoard `docs/draft/index.html:377-379`).
- Fork sincroniza com `upstream/main` (`README.md:7-21`); substituir literais EN por PT inline geraria conflitos crônicos.
- Catálogos existentes são dicts Python embutidos (`_INSTRUCTION`, `_TEMPO_SPEECH`, `LANE_MACRO`, etc.), não JSON.
- Freeze: `--onedir` + `--hidden-import`; data files via `Copy-Item` no stage (`dist/build.ps1:53-58`). Módulo Python no `core/` entra no bundle se importado / listado em `$hidden`.
- `tagcheck` usa substring case-insensitive (`tools/tagcheck.py:32-43`). Glyphcheck ignora acentos Latin-1 (`ord > 0x2000`).

## Desired End State

1. Com default (instalação limpa), UI/coach/tags/boards/DraftBoard/chrome aparecem em **português brasileiro**.
2. Inglês permanece como msgid no código; traduções vivem em `core/i18n_pt_BR.py` (dict msgid → msgstr).
3. `ui_lang` em settings (`pt_BR` | `en`); default `pt_BR`. Runtime, não flag de build.
4. Após a fase 9: Settings → Language permite trocar; Save persiste; superfícies aplicam (reabrir / releitura documentada).
5. DraftBoard: payload inclui `lang` do host; chrome + DDragon seguem esse lang.
6. `python tools/selftest.py` (e tag/glyph guards relevantes) verdes; acentos PT legíveis nas boards.
7. Sync upstream: merge atualiza msgids EN; strings novas caem em EN até entrar no catálogo (fallback).

### Key Discoveries:
- Padrão de nova pref: declarar em `STRINGS` → var Tk → `cfg.save` (`smiteconfig.py:134-221`, `smitesettings.py` Save ~754+).
- Install root frozen: `dirname(dirname(sys.executable))` (`tools/smiteupdate.py:46-50`).
- Tray release já lê settings JSON (`dist/tray.ahk:22`, `205`) — mesmo path serve para `ui_lang` nos menus AHK.
- Templates devem ser msgid completo: `t("GO {lane} — best gank").format(lane=...)`, nunca f-string com pedaços `t()` soltos.

## What We're NOT Doing

- Voz Polly / ttsmp3 em português (texto do callout pode ser PT; voice name continua `"Salli"` / EN).
- Traduzir automaticamente tips scrapados do MOBAFire/counterstats (permanecem EN; atribuição/UI wrapping via `t()`; path LLM pede PT quando `ui_lang=pt_BR`).
- Reescrever o README/docs de produto em PT (exceto o que for necessário para TAGS/spec de tags renderizadas).
- i18n gettext/`.po` / JSON de catálogo.
- Congelar idioma no build / builds separados por locale.
- Live hot-swap perfeito de todos os processos AHK sem reabrir tray (fase 9 documenta reopen).
- Quebrar invariantes: grades = performance in-game; tags citam evidência; DraftBoard side-by-side; links curtos `#d=`.

## Implementation Approach

**API mínima** em `core/smitei18n.py`:

```python
# Conceptual shape — implement in Phase 1
SUPPORTED = ("pt_BR", "en")
DEFAULT_LANG = "pt_BR"

def lang():
    """Read ui_lang from smiteconfig; normalize; default pt_BR."""

def set_lang(code):
    """In-process override after Settings save (optional helper)."""

def t(msgid: str) -> str:
    """Lookup catalog for lang(); missing → msgid (English)."""

def tf(msgid: str, **kwargs) -> str:
    """t(msgid).format(**kwargs) — preferred for templates with variables."""
```

**Catálogo:** `core/i18n_pt_BR.py` com `MESSAGES = {"English msgid": "Tradução PT", ...}`. Locale `en` = identity (sem arquivo, ou dict vazio).

**Wiring:** call sites trocam `"Foo"` por `t("Foo")` e f-strings por `tf("... {x} ...", x=...)`. Dicts de módulo passam a valores resolvidos em runtime (funções/`t()` no lookup) ou wrappers que traduzem na leitura — não duplicar lógica.

**Boot:** cada entry (`smiteless_main` paths / `ui/*.py` mains) pode chamar `smitei18n` implicitamente no primeiro `t()`; não precisa de init global pesado. `ui_lang` lido via `cfg.load()` dentro de `lang()` (cache curto opcional).

**Upstream sync:** commits de catálogo e de `t()`-wrap separados da lógica quando possível; após merge, traduzir msgids novos no catálogo.

## Performance Considerations

- `t()` deve ser dict lookup O(1); evitar releitura de arquivo por chamada (catalog import once).
- `lang()` pode cachear com invalidação no Save; overlays que já fazem `cfg.load()` periódico não devem adicionar I/O extra pesado.
- DDragon: segundo locale = segundo cache em disco; ok. Não refetch a cada frame.
- Release freeze continua multi-minuto — fora de jogo.
